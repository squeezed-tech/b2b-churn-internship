## Неделя 2 — Определение обучающей выборки

### Определение target

**Объект наблюдения:** клиент.

Каждая строка итоговой обучающей выборки соответствует одному клиенту
в конкретную дату snapshot.

**Событие оттока:** клиент считается ушедшим, если после даты snapshot
в течение окна прогнозирования наступает формальное расторжение договора,
зафиксированное в `termination_date`.

`current_status` не используется для формирования target, поскольку это
текущий статус клиента на конец июня 2026 года и при историческом snapshot
может содержать информацию из будущего.

### Окно наблюдения

Используется окно наблюдения длиной 6 месяцев, предшествующее snapshot.

Признаки рассчитываются только по данным, доступным до момента snapshot.

Например, для snapshot 2025-06-01 используются данные с декабря 2024
по май 2025 включительно.

### Окно прогнозирования

Используется окно прогнозирования длиной 3 месяца после snapshot.

Target равен 1, если в течение этого окна у клиента наступает
termination_date, иначе target равен 0.

### Принцип защиты от data leakage

При построении признаков не используются данные, которые стали известны
после момента snapshot.

В частности, `current_status` не используется в качестве признака или
для формирования target, поскольку он отражает состояние клиента
на конец всего периода наблюдения (июнь 2026).
